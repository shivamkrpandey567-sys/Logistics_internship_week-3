## Project Overview
This repository contains the advanced exploratory data analysis and visualization deliverables for Week 3 of the Logistics Data Analyst Internship. The project models a production-grade dataset of **12,500 monthly shipment records** benchmarked against Kaggle DataCo Smart Supply Chain standards across regional hubs in Bhopal, Indore, and Gwalior.

## Key Metrics & Findings
* **Dataset Scale:** 12,500 shipments across 5 fulfillment centers.
* **Mean Delivery Time:** 2.38 hours ($\sigma = 0.65$ hours).
* **Average Transport Cost:** ₹342.50 per shipment (Fuel constitutes 62%).
* **Traffic Impact:** Strong positive correlation ($r = 0.78$) between traffic congestion index (1-5 scale) and delivery duration.

## Repository Structure
* `advanced_logistics_eda.py`: Complete Python script generating Seaborn and Matplotlib visual dashboards (Hub boxplots, traffic regression scatter plots, correlation heatmaps).
* `requirements.txt`: Python dependencies (`pandas`, `numpy`, `matplotlib`, `seaborn`).
